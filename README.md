# Knowledge Graphs: From Triples to Retrieval

- knowledge_graphs_note.pdf : the LaTeX note (29 pages); source in note/
- knowledge_graphs_lab.ipynb : ten-lab executed notebook (runs in about 20 s)
- data/ : synthetic Meridian Analytics files, with a data dictionary in data/README.md
- scripts/generate_data.py : regenerates the data deterministically (seed 2026)

Requirements: pandas, numpy, scipy, scikit-learn, networkx, rdflib, matplotlib.
